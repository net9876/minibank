# MiniBank

A synthetic banking-operations sandbox for exploring how business workflows, Power Platform, Azure services and AI agents fit together: from a simple payment lookup to a multi-agent counterparty investigation.

**Status: work in progress.** This is an ongoing engineering project. Results are intermediate, the scope keeps growing (new scenarios, services, agents and flows), and some parts are unfinished or not yet verified. The case study with the current state of each capability is at <https://handsonazure.com/projects/minibank/>.

**All data is synthetic.** Payments, customers, accounts and beneficiaries are generated by a seeded script and exist only for this lab. The only real data is public legal-entity records from the GLEIF registry, kept separate from the invented payments. MiniBank does not process money, keep a ledger, do KYC or connect to payment networks.

## What is in the repository

| Path | What |
| --- | --- |
| `api/` | Azure Functions payments API (lookup, hold explanation with a cited policy section) and the Power Platform custom connector definition |
| `counterparty/` | Counterparty investigation: two Foundry agents run by a Python worker (Microsoft Agent Framework), GLEIF client, FIBO subset (RDF), queue and Dataverse store, fixture tests, Power Apps and Teams approval assets |
| `data/` | SQL schema, deterministic synthetic data generator and loader, versioned policy documents |
| `infra/` | Terraform: base lab, Foundry project, API Management with the on-demand MCP gateway, operations |
| `scripts/` | PowerShell for deployment, data and policy loading, connector export, and the start/stop lifecycle that avoids idle cost |
| `docs/` | Design (in Russian), run guides for the counterparty scenario, Copilot Studio and the lifecycle |

## Running it

You need your own Azure subscription and Power Platform environment. Nothing here contains credentials: tokens come from your own `az login`, Read-Host prompts or managed identities. The files that hold your subscription IDs and Terraform backend settings (`infra/backend.local.hcl`, `infra/*.auto.tfvars.json`, `*.tfplan`) are generated by `scripts/Initialize-Azure.ps1` and are git-ignored. Do not commit them.

Start with `docs/MiniBank-Counterparty.md` and `docs/MiniBank-Lifecycle.md`. Deploying creates billable Azure resources.
